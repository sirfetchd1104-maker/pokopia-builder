# Pokopia Builder

**포코피아 빌딩 시뮬레이터** — 포코피아에서 건물을 짓기 전에 미리 설계해볼 수 있는 3D 블록 플래너입니다.

> 🔗 **Live**: [Cloudflare Pages에서 운영 중](https://pokopia-builder.sirfetchd1104.workers.dev/)

## 조작법

| 동작 | 키 |
|------|-----|
| 블록 설치 | 마우스 좌클릭 |
| 블록 제거 | 마우스 우클릭 |
| 이동 | W / A / S / D |
| 상하 이동 | Space / Shift |
| 블록 종류 | Q (순차 전환) |
| 회전 | R |
| 일괄배치 토글 | E (끄기 → 앞 → 오른쪽 → 위 → 면적) |
| 대칭배치 토글 | T |
| 블록 교체 | G (조준 중인 블록의 모양/회전 교체) |
| 범위 선택 | F (두 번 눌러 시작점/끝점 지정) |
| 선택 삭제 | Delete / Backspace |
| 선택 이동 | Ctrl+↑↓←→ · Ctrl+. / Ctrl+, (범위 선택 시) |
| 선택 회전 | Ctrl+R (범위 선택 시 90° 시계 방향) |
| 스크린샷 | P |
| 되돌리기 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 카메라 고정/해제 | Tab |
| 블록 전체 이동 | Ctrl+↑↓←→ · Ctrl+. / Ctrl+, (범위 미선택 시) |
