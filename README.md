# Pokopia Builder

**포코피아 빌딩 시뮬레이터** — 포코피아에서 건물을 짓기 전에 미리 설계해볼 수 있는 3D 블록 플래너입니다.

> 🔗 **Live**: [Cloudflare Pages에서 운영 중](https://pokopia-builder.sirfetchd1104.workers.dev/)

### v1.0 — 2026.06.24 (최초 배포)

- Three.js 기반 3D 블록 에디터
- 블록 배치 / 삭제 (좌클릭 / 우클릭)
- 다양한 블록 종류: 기본 블록, 지붕(웨지), 지붕 모서리
- 블록 회전 (0° / 90° / 180° / 270°)
- 색상(재질) 관리: 추가, 삭제, 이름 변경, 색상 변경

- 대칭 배치 (좌우 / 앞뒤)
- 레이어 필터 (전체 / 해당 층만 / 해당 층 이하)
- 실행 취소 / 다시 실행 (`Ctrl+Z` / `Ctrl+Y`)
- 블록 복사 / 붙여넣기 (`Ctrl+C` / `Ctrl+V`)
- JSON 저장 / 불러오기
- 자동 저장 (localStorage)
- FPS 스타일 카메라 (WASD + 마우스)
- Pointer Lock 기반 조작
- 방향 표시 라벨 (앞/뒤/좌/우)

## 조작법

| 동작 | 키 |
|------|-----|
| 블록 설치 | 마우스 좌클릭 |
| 블록 제거 | 마우스 우클릭 |
| 이동 | W / A / S / D |
| 상하 이동 | Space / Shift |
| 블록 종류 | 1 (기본) · 2 (지붕) · 3 (모서리) |
| 회전 | R |
| 일괄배치 토글 | E |
| 대칭배치 토글 | T |
| 되돌리기 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 카메라 고정/해제 | Tab |
| 블록 전체 이동 | Ctrl+↑↓←→ (상하좌우) · Ctrl+. / Ctrl+, (위/아래) |
